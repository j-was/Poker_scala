# PokerScale Frontend

Część frontend'owa aplikacji PokerScale. 
Implementuje widok aplikacji desktopowej napisanej przy użyciu framework'a ScalaFX.

## Uruchomienie

Wymagania:

- JDK 17 lub nowszy
- sbt

```bash
cd frontend
sbt run
```

Struktura:

- `build.sbt` - konfiguracja projektu i zalezność ScalaFX
- `project/build.properties` - wersja sbt
- `src/main/scala/poker/frontend/PokerApp.scala` - punkt wejścia aplikacji
